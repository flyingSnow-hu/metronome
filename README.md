# GraduaMetro

> 为变速、变拍数练习设计的移动端节拍器。

 **变速节拍器** 是一款使用 Unity 开发的竖屏移动端节拍器。用户可以把一首曲子定义为按小节发生的一组事件，在播放时自动应用速度、拍数、细分和强弱拍的变化，适合练习速度变化或不规则拍数的乐曲段落。

## 功能

- **曲子管理**
  - 新增、编辑、删除曲子
  - 本地 JSON 持久化
  - 支持将曲子数据作为文件分享、导入

- **按小节编排事件**
  - 变速
  - 线性曲线变速（指定开始小节、结束小节、起始 bpm、目标 bpm）
  - 变拍数（每小节 1～8 拍）
  - 变细分音（每拍 1～8 个细分音）
  - 变强弱拍（强弱、全强、全弱）

- **事件编辑**
  - 使用自然语言式模板内联编辑参数
  - 例如：`第 10 小节，变速到 80`
  - 事件自动按小节与事件类型排序
  - 保存时检查参数范围和事件冲突

- **播放控制**
  - 0.25×、0.5×、1×、2×、4× 全局播放速度倍率
  - 可选倒计时（默认 3 秒）
  - 强音、弱音与独立音频偏移补偿
  - 暂停、继续与播放完成后重播

- **播放可视化**
  - 显示曲名、播放倍率、当前小节/总小节数
  - 显示当前 bpm、拍数、细分音与强弱拍模式
  - 显示全曲进度、小节内拍进度和事件时间轴

- **移动端适配**
  - Android 竖屏优先
  - 安全区适配，避免刘海、挖孔和底部手势区域遮挡内容

## 规则摘要

- 事件都在其指定小节的开始生效。
- 曲线变速按小节线性插值；结束小节的速度等于目标速度，插值 bpm 四舍五入为整数。
- 强弱模式下，第 1 拍及其全部细分音使用强音，其余拍使用弱音。
- 不同属性可在同一小节变更；同一小节中多个事件同时修改同一属性会被判定为冲突。
- 合法 bpm 范围为 **20～300**。
